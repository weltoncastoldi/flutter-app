# 🚀 Desafio Flutter: Animações no primeiro app

## 🎯 Objetivo

Seu tech lead apresentou uma implementação do aplicativo com animações nas palavras e pediu que você reproduza esse comportamento no seu projeto atual.

Sua missão é analisar o código de referência, identificar as diferenças e adaptar sua implementação, **sem simplesmente copiar e colar o código pronto**.

## 👀 Referência visual

![Demonstração das animações do app Flutter](https://codelabs.developers.google.com/codelabs/flutter-codelab-first/img/d4afd1f43ab976f7.gif)

🔗 **[Acesse o código de referência no DartPad](https://dartpad.dev/?id=e7076b40fb17a0fa899f9f7a154a02e8)**

## 🛠️ Etapas do desafio

1. **Investigue:** execute o DartPad e observe como as animações funcionam.
2. **Compare:** analise as diferenças entre o código de referência e o seu projeto.
3. **Implemente:** adapte seu código para reproduzir as animações observadas.
4. **Teste:** verifique se a geração de palavras e as funcionalidades de favoritos continuam funcionando corretamente.

## 💡 Dica

Investigue os widgets e as propriedades responsáveis pelas animações antes de alterar seu código. O objetivo é aprender a compreender e adaptar uma implementação existente, e não apenas reproduzir o resultado visual.

**Bom desafio! 🚀**
